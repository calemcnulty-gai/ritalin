# Installing Ritalin for Cursor (Alpha)

Thank you for testing the alpha version of Ritalin! 🎮

## Quick Install

1. **Download the extension**:
   - Go to [Releases](https://github.com/calemcnulty-gai/ritalin/releases)
   - Download `ritalin-0.1.0-alpha.1.vsix`

2. **Install in Cursor**:
   - Open Cursor
   - Press `Cmd+Shift+P` (Mac) or `Ctrl+Shift+P` (Windows/Linux)
   - Type "Install from VSIX"
   - Select the downloaded `.vsix` file
   - Reload Cursor when prompted

3. **First time setup**:
   - Open any project in Cursor
   - The extension will create necessary files automatically
   - Press `Cmd+Shift+P` → "Ritalin: Show Configuration Page"
   - Download and select a game

## Testing the Extension

1. Start writing code and use Cursor's AI features
2. Games should appear automatically when AI is generating
3. The game window will hide when AI is done

## Reporting Issues
