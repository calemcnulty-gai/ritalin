# Release Notes

## v0.1.0-alpha.1 - Initial Alpha Release

### 🎮 Features

- **AI Detection**: Automatically detects when Cursor AI is generating code
- **Game Window**: Shows mini-games in a floating window during AI generation
- **Game Library**: Download and play games from itch.io
- **Configuration UI**: Beautiful settings page to manage games and preferences
- **Multi-Engine Support**: Supports Unity WebGL, PICO-8, and HTML5 games

### 🚀 Getting Started

1. Install the extension from the .vsix file
2. The extension will automatically create necessary files in your workspace
3. Select a game from the configuration page (Cmd+Shift+P → "Ritalin: Show Configuration Page")
4. Start using Cursor AI - games will appear automatically!

### ⚠️ Known Issues (Alpha)

- Game window positioning may need adjustment on multi-monitor setups
- Some itch.io games may fail to download (working on engine detection)
- Performance impact on lower-end machines when games are running
- Electron window may occasionally fail to spawn (restart Cursor if this happens)
